# 智能家居 iOS

App 默认连接已配置的 HTTPS 后端和温湿度设备，打开后自动获取最新数据、历史记录及曲线。

GitHub Actions 从仓库加密变量 `SMART_HOME_API_TOKEN` 生成临时 `SmartHome/ServiceConfig.plist`，在编译时将密钥打入 IPA；该文件不得提交源码仓库。更换后端 API 密钥后，必须同步更新 Actions 密钥并重新构建、重新安装 App。

IPA 自带密钥，任何拿到安装包的人都有可能提取并访问后端，因此应仅向可信人员分发。该密钥目前与现有后端访问令牌相同，后续提供设备控制功能之前需要改造为权限受限的专用凭据和用户认证。不要将安装包发布到公开位置。

Actions 生成未签名 IPA，需要自行签名安装。运行设备需 iOS 16 或更高版本。
