# iOS 智能家居

首次打开使用后端账号密码登录。登录成功后 App 将会话令牌保存在本机钥匙串。勾选「记住密码」后，账号和密码也保存在本机钥匙串。会话有效期 24 小时，服务重启后需重新登录。设置页可退出登录。

从首页可查看五项环境读数、开关黄灯和风扇，以及进入 RGB 灯、门、窗各自的页面。门、窗操作要经过确认，页面显示最后一次舵机指令和位置确认状态。使用自选颜色、六种灯效及灯效定时需要同时更新后端与控制板固件。

GitHub Actions 构建不再依赖 API 密钥，也不再打入 ServiceConfig.plist。生成未签名 IPA，自行签名后安装，最低支持 iOS 16。
